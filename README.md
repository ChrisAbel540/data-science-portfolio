# Data Science Portfolio

Welcome to my **Data Science & Data Analysis Portfolio**! This repository contains a suite of projects I’ve been working on for self-learning and personal interest — each demonstrating my skills in exploring data and creating meaningful insights.

---

## 🔍 Featured Projects

### 1. Food Intolerance Study
- **Goal:** Identify likely food intolerances by analysing the time-delayed relationship between allergen intake and gastrointestinal reactions.
- **Tech:** Python, pandas, NumPy, matplotlib, cross-correlation analysis.
- **Insights:** Used cross-correlation to link symptom onset with specific allergens. Found that dairy and sulphites had the strongest delayed correlations with reported reactions. Normalised results to account for ingestion frequency. This approach enabled early identification of trigger foods - confirmed later by medical professionals - demonstrating the potential of time-series analysis for personal health diagnostics.

### 2. Motorcycle Price Estimator
- **Goal:** Predict eBay motorcycle sale prices using listing information.
- **Tech:** Python, scikit-learn (Random Forest Regression), pandas, matplotlib.
- **Insights:** Insights: Identified key factors influencing price, such as mileage, model year, and manufacturer. Used a trained model to flag over- or underpriced listings, enabling data-driven buying recommendations. Feature importance analysis highlighted practical insights for sellers and buyers.
